# Cloud Pricing Lab
## Strategic Decision-Making in Cloud Resource Allocation

**Project:** Game-Theoretic Pricing Competition Model  
**Group members:** Rishi Bhardwaj · Jaskirat Singh · Kunal Tyagi · Yash Tyagi

Cloud Pricing Lab is an interactive demonstration of pricing competition between illustrative cloud-resource providers. Users can change market demand, price sensitivity, provider costs, and the number of providers, then compare equilibrium prices, demand, and profit. This is an academic model, not a live cloud-pricing service.

## Features

- Adjust total modeled demand and price sensitivity.
- Edit provider names and marginal costs; use between two and six providers.
- Calculate equilibrium prices using a grid-based best-response process.
- Compare price convergence, demand, profit, and results as the number of providers changes.
- Run the interface directly in a browser or publish it with GitHub Pages.

## Run locally

Open `index.html` in a modern browser. No package installation or backend server is required. Alternatively, run a local HTTP server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a repository, for example `cloud-pricing-game`.
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, and `app.js` together.
3. Open **Settings → Pages**.
4. Choose deployment from the `main` branch and `/(root)`, then save.
5. Open the URL provided by GitHub Pages and test the controls before presenting.

No API key, build step, or third-party JavaScript library is required. The stylesheet uses a web font when available and falls back to system fonts.

## Model

The browser model mirrors the supplied `cloud_pricing_game.py` implementation.

| Setting | Value |
|---|---:|
| Default modeled demand | 2,000 units |
| Default price sensitivity (α) | 1.2 |
| Default marginal costs | 1.8, 2.2, 2.0 |
| Candidate prices | 200 evenly spaced values from 0.5 to 10.0 |
| Initial prices | 1.5 × marginal cost |
| Convergence tolerance | 0.001 |
| Iteration limit | 100 |

The providers update their prices simultaneously in each round using best responses to the previous round's prices. The default equilibrium prices are approximately **3.126** (AWS-like), **3.364** (Azure-like), and **3.269** (GCP-like).

The separate competition experiment compares two to six symmetric providers, each with marginal cost 2.0 and price sensitivity α = 1.5. Its modeled demand scales as `1000 × provider count / 3`, as in the original Python code.

The provider names are illustrative and do not represent real cloud offers. Demand is allocated among the active providers using a multinomial-logit share based on price. The model does not represent capacity limits, service quality, switching costs, contracts, fixed costs, or different customer segments. Results should be interpreted within these assumptions rather than as predictions of actual cloud prices.

## Verify the browser model

With Node.js installed, run:

```bash
node tests/model_smoke_test.js
```

The smoke test checks baseline equilibrium prices, selected demand and profit values, and competition results. Node.js is only needed for this optional test; the website itself runs in the browser.
